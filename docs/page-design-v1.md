## 0. 全局设计语言

| 项目 | 规则 |
| --- | --- |
| 主色 | `#2B5CE6`（按钮填充 / 选中态 / 链接），按压 `#1E49C4` |
| 辅色 | `#EE6C2D`（金额 / 加急 / 角标） |
| 语义色 | 成功 `#0E9F6E`、警告 `#D97706`、危险 `#E02424`，各自只分「文字档 / 填充档 / 淡底档」三档 |
| 背景 | 页面 `#F5F7FA`、卡片 `#FFFFFF`、卡内嵌块 `#F1F4F9` |
| 文字 | `#0F172A` 标题 / `#475569` 次文本 / `#6B7688` 辅助 / `#9AA5B4` 占位 |
| 字号阶梯 | 52 / 44 / 34 / 30 / 28 / 24 / 22 rpx 共 6 档，不在页面里随手写新字号 |
| 圆角 | 卡 28rpx、小卡与输入框 16rpx、内嵌块 8rpx、按钮胶囊 999rpx |
| 间距 | 4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48 rpx，页面左右统一 32rpx |
| 阴影 | 卡片 `0 2rpx 8rpx rgba(15,23,42,.05)`，浮起 `0 6rpx 20rpx rgba(15,23,42,.08)` |
| 触控 | 可点元素热区 ≥ 88rpx（约 44pt）；动效 120 / 220 / 320 / 400ms 四档 |
| 图标 | 全部 CSS 几何绘制（`app.wxss` 第 6 节），**不使用 emoji、不引入图片图标** |
| 无障碍 | 每页自带 `prefers-reduced-motion: reduce` 降级 |

### 本轮统一修掉的视觉问题
1. **按钮宽度不再三种混用**：一屏只允许「通栏主按钮 / 并排等宽（含次要）/ 卡内小按钮」三种宽度，同一行最多 1 个主按钮。
2. **描边卡片统一改为「白底 + 浅描边 + 微阴影」**，不再出现「纯描边无底色」的 Demo 感卡片。
3. **状态色只出现在语义位置**（状态胶囊、金额、提示条），装饰性色块全部退成品牌淡底。
4. **表单/列表行间距固定 12rpx，区块之间固定 32rpx**，避免「一会儿挤一会儿空」。
5. **空状态只有一种语言**：淡灰圆底 + 三横线 + 一句可执行引导，不再每页换一个图形。

## 1. 登录（pages/login）

- **结构**：导航栏「校园跑腿」→ 品牌方块 Logo + 名称 + Slogan → 白色登录卡（账号输入 / 密码输入 + 小眼睛 / 主按钮 / 一行两个蓝色链接）→ 协议提示行 → 安全提示行。
- **关键点**：
  - 单输入框占位符「手机号或账号 ID」，后端自动识别 11 位手机号与账号 ID。
  - 密码框右侧是**应用级小眼睛**（88rpx 圆形热区，按下变浅灰底），点击切换明文/密文。
  - 「忘记密码」「还没账号？去注册」是独立低层级链接，不再和按钮挤在一起。
  - 协议行用最弱的 `--text-4`，书名号内文字用主色。
  - 底部补一行「设备变更需密保解锁 · 连续 5 次密码错误锁定 15 分钟」，把风控前置告知用户。

## 2. 注册（pages/register）

- **结构**：三步指示「① 账号 ② 密保 ③ 完成」→ 账号 ID（前缀 X 锁定块 + 后缀输入 + 「随机」按钮）→ 密码 + 三段强度条 → 确认密码 → 手机号（选填，右侧注「仅用于人工联系」）→ 密保问题 1（**上：问题 / 下：答案**）→ 密保问题 2 → 协议勾选 → 底部固定主按钮。
- **关键点**：
  - 密保严格遵循「上方是问题、下方是答案」的两行结构，不再挤在同一栏。
  - 问题框是可输入的自定义框 + 右侧下拉箭头（既能选预设也能自己写）。
  - 协议勾选框显示为**未选中的空方框**（注册时必须主动勾选），链接文字蓝色。
  - 长表单底部固定操作条，用户不必滑到底再找按钮。

## 3. 忘记密码（pages/forgot）

- **结构**：顶部蓝色提示条（已认证账号需填账号 ID + 学号 + 姓名 + 2 道密保）→ 账号 ID / 学号 / 姓名 → 2 道密保答案 → 图形验证码（题目框 + 答案框）→ 主按钮。
- **关键点**：未认证账号隐藏「学号」一行；图形验证码只占两栏高度，不再是巨大一张图。

## 4. 密保设置（pages/securitySetup）

- **结构**：导航「设置密保问题」（无返回）→ 橙色提示卡（首次登录必须设置 + 后果说明）→ 两张密保卡（问题下拉 + 答案输入）→ 主按钮 → 底部小字说明修改入口。
- **关键点**：用警告色而非危险色，强调「必须做」而不是「出错了」。

## 5. 首页 / 任务大厅（pages/index）

- **结构**（自上而下）：品牌 + 身份提示一行 → 搜索独占一行 + 右侧「筛选」胶囊（有生效条件时右上角亮橙点）→ **进行中任务置顶深色卡** → 金刚区 5 宫格 → 「可接任务 / 共 N 条」→ 任务卡列表 → 分页提示。
- **关键点**：
  - **删掉超大「任务大厅」标题**（导航栏已写校名，避免标题重复）。
  - 排序与酬金区间全部收进**底部 Sheet**（遮罩 + 上滑动效 + 「重置 / 确定」），首屏高度让给任务。
  - 置顶卡用深色渐变 `#22314F → #0F172A` 承载「我有一单在跑」：左侧角色标签，右侧**实时倒计时**（等宽数字），下方进度条 + 地址 + 金额；超时后倒计时转浅红。
  - 金刚区：取快递 / 食堂带饭 / 打印资料 / 超市代买 / 自定义发布，各自一种淡底 + 同色图标；「取快递」右上角挂「免费×1」橙色角标；点击跳发布页并预填模板（`?tpl=key`）。
  - 任务卡保留产品硬要求：头像 / 昵称 / 账号 ID / 学号 / 绿「已认证」徽章（管理员显示红「管理员」徽章）。

## 6. 发布任务（pages/publishTask）

- **结构**：快捷模板 4 个胶囊（选中态主色淡底 + 主色描边）→ 表单（收件人姓名* / 手机号* / 取件码 / 送达地址* / 酬金* / 详细地址 / 备注 / 限时二选一 / 物品照片*）→ 底部固定条（平台服务费 + 「免费发布 / 去支付」主按钮）。
- **关键点**：
  - 酬金框用主色描边强调必填，右侧注「最低 0.50 元」。
  - 必填项统一带红色星号；照片区明确写「至少 1 张」，未满足时底部按钮置灰。
  - 使用邀请权益时，底部变成绿色「¥0.10（本次邀请权益已抵扣）」，按钮文案切为「免费发布」。

## 7. 任务详情 · 雇主视角（pages/taskDetail）

- **结构**：状态卡（成功色淡底 + 「待雇主确认」+ 右侧剩余确认时间）→ 送达照片 3 张 → 任务人员两张 mini 卡片（头像 / 昵称 / 账号 ID / 学号 / 认证徽章）→ 任务信息表（订单号 / 送达地址 / 详细地址 / 取件码 / 收件人 / 酬金与服务费）→ 底部「未送达」（次要）+「确认送达」（主）。
- **关键点**：点「确认送达」弹出**二次确认弹窗**，「否」始终可点，「确定」按钮显示 确定 3 → 2 → 1 倒计时，倒计时结束才可点。

## 8. 任务详情 · 接单者视角（pages/taskDetail）

- **结构**：状态卡（警告色淡底 + 「进行中 · 配送中」+ 右侧倒计时）→ 送达照片上传区（1 张实拍 + 2 个虚线加号位）→ 任务人员两卡 → 任务信息表 → 「取消接单」→ 底部固定「提交已送达」（未上传照片时置灰，上方提示「请先上传送达照片」）。

## 9. 我的发布（pages/myPublish）

- **结构**：状态分组胶囊（全部 / 待接单 / 进行中 / 待确认 / 已完成，带数量）→ 任务卡（左侧状态色条 + 地址 + 类型标签 + 金额 + 订单号 + 状态胶囊 + 右侧操作按钮）。
- **关键点**：按钮按状态出现——待接单「编辑 / 撤销」，进行中「加酬金」，已完成无按钮；「撤销」用中性次要样式避免误触。

## 10. 我的任务（pages/myTake）

- **结构**：状态胶囊（进行中 / 待确认 / 已完成）→ 卡片：地址 + **倒计时** + 进度条 + 取件码/限时 + 联系人 + 雇主小行 + 「提交已送达」；第二张卡展示「待确认」态。
- **关键点**：底部 tabBar「我的任务」有未完成任务时显示数字气泡（1 条显示 1，2 条显示 2）。

## 11. 编辑任务（pages/taskEdit）

- **结构**：顶部蓝色提示条（可编辑范围 + 3 分钟间隔）→ 表单 → 酬金框下方橙色加粗「酬金仅可提高，不可降低」→ 底部「取消 / 保存修改」。
- **关键点**：进行中任务进入本页时，除酬金外所有字段呈只读态（灰底、不可聚焦）。

## 12. 消息中心（pages/message）

- **结构**：右上角「一键清除」→ 分类胶囊（全部 / 系统 / 管理员 / 任务 / 雇主）→ **紧凑消息列表**（类型色圆底图标 + 标题 + 单行摘要省略 + 时间 + 未读红点）→ 底部提示。
- **关键点**：行高压到约 104rpx，一屏可见 6 条以上；整行可点进消息详情。

## 13. 消息详情（pages/messageDetail）

- **结构**：类型胶囊 → 标题（加粗大字）→ 时间 → 分隔线 → 正文段落 → 关联任务卡（地址 + 类型 + 订单号 + 「查看详情」）。
- **关键点**：关联任务卡整块可点，直接跳任务详情。

## 14. 我的（pages/profile）

- **结构**：品牌淡底资料卡（头像 + 在线点 + 昵称 + 认证徽章 + **账号 ID 可点击复制** + 「可用于登录」说明 + 邀请码可复制）→ 三格数据（发布 / 接单 / 完成率）→ 分组列表「账号与安全」「我的服务」→「退出登录」（次要按钮）→「注销账号」（危险色文字）→ 页脚 QQ 群提示 → tabBar。
- **关键点**：账号 ID 与邀请码都带复制图标 + 「点击复制」提示，整行可点；忘记密码与账号 ID 功能分开，不再混淆。

## 15. 收支账单（pages/bill）

- **结构**：品牌渐变汇总卡（左「本月收入」、右「本月支出（服务费）」，各带累计单数）→ 「流水明细 / 按时间倒序」→ 流水列表（类型色图标 + 类型名 + 摘要 + 时间 + 右侧带符号金额）→ 底部说明。
- **关键点**：**没有任何提现入口**，底部明确写「平台不托管酬金，账单仅作记账展示」；每条流水可点跳任务详情。

## 16. 校园认证（pages/campusCert）

- **结构**：红色规则卡（「图片需上传本人在智慧校园中打开身份卡页面……」+ 右侧示例图缩略）→ 剩余次数提示（红色加粗）+ 权限说明 → 表单（真实姓名* / 真实学号* / 可联系手机号* / 校园身份截图*）→ 主按钮。
- **关键点**：上传区写明「提交成功后表单将自动清空」；提交后弹窗告知 7 天内剩余次数。

## 17. 修改资料（pages/auditApply）

- **结构**：头像 / 昵称两个 Tab → 头像卡（当前头像 + 说明 + 「选择图片」）→「提交审核」→「我的申请记录」（通过 / 驳回带原因 / 待审核三条）。
- **关键点**：通过用绿色胶囊、驳回用红色胶囊，胶囊内边距收紧，不再出现「文字背后框明显大一圈」。

## 18. 申诉（pages/appeal）

- **结构**：次数提示条（「今日剩余申诉次数：1 / 2」+ 右侧「每日 0 点重置」）→ 申诉内容文本域（右下角字数）→「提交申诉」→「我的申诉记录」（待处理 / 已回复，已回复带管理员回复灰底块）。

## 19. 我的设备（pages/devices）

- **结构**：顶部蓝色说明条（新设备顶掉旧设备 + 非本人设备需密保解锁）→「当前设备」卡（主色描边 + 设备图标 + 型号 + 「本机」胶囊 + **IP 归属地「河南-南阳」** + 最近登录时间 + 设备标识）→「历史设备」列表 → 底部提醒。

## 20. 管理后台（pages/admin）

- **结构**：管理员红色渐变头卡（管理员 · A0001 / 学号 20240001 / 今日待办 N）→ 四格统计（待审核 / 待回复申诉 / 待处理举报 / 封禁中，各自语义色）→ 八宫格功能入口（审核管理 / 用户管理 / 订单管理 / 申诉处理 / 举报处理 / 封禁管理 / 消息推送 / 数据统计）→「最近待办」列表（每条右侧「去处理」）。
- **关键点**：管理员用红色系表达「最高权限 + 无次数限制」，与普通用户的蓝色体系明确区分。

## 需要你确认的 3 件事

1. **任务卡信息密度**：规范板第 08 节原本建议「列表只留地址 + 类型 + 金额」，但你此前明确要求「每条任务都要显示头像、昵称、账号 ID、学号、认证标志」。本稿按**后者**执行（信息更全，但单卡更高）。是否保持？
2. **首页金刚区**：5 个入口挤在一行，本稿**隐藏了金刚区下方的小字说明**（如「限时60 · ¥0.8」），只留图标 + 名称。若希望保留说明，需要改成可横向滑动的一行。
3. **落地范围**：确认后我按此稿逐页调整 WXSS（**不动任何 JS 逻辑、不删任何功能**），改完统一跑 15 个回归脚本。
